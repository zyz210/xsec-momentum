# 최종 명세 + 실증 결과: 4H 크립토 모멘텀 엣지 (v0.3)

> 프로젝트 질문: **"4H 크립토에 자동화 가능한, 실제로 돈 되는 엣지가 존재하는가?"**
> 현재 답: **존재한다 — 모멘텀 엣지. 강건성·자산간 일반화·OOS 유의성 3관문 통과.
> 단 (1)실제 펀딩 확정, (2)불장 편향 보정, (3)포워드/실전 검증은 남았다.**

## 3. 확정된 것 vs 남은 것

**확정:**
- 모멘텀 엣지 존재. 강건성 ✓, ETH 자산간 일반화 ✓, 통합 OOS 통계 유의 ✓.
- 역추세(나씨식) 방향은 이 시장에서 손실. 추세추종이 정답.
- 롱+숏이 롱온리보다 우월(수익·낙폭·펀딩내성 모두).

**남은 관문 (실전 진입 전 필수):**
1. **실제 펀딩 데이터** — `fetch_data.py`(Binance API, 무료, 로컬 실행)로 받아 `--funding`으로 재검증. 롱+숏 펀딩중립성 크기 확정.
2. **불장 편향 보정** — OOS 구간(2024~25)이 강세장이라 모멘텀에 유리했음. 횡보·약세 구간 별도 성과 확인 필요.
3. **다심볼 확대** — SOL 등 추가로 통합 IS도 유의(현재 경계선)로 밀어올리기.
4. **포워드/페이퍼 → 초소액 실전 게이트** — 돈 없이 로그부터. 실체결·슬리피지·심리 반영.

## 4. "최대 수익" 관련 주의
트레이드당 기대값 최대(예: ROC임계 8% → +0.37R)는 트레이드 수가 급감(174건)해 총수익·복리 기회가 줄어든다.
**기대값 최대 ≠ 총수익 최대**이며, 파라미터를 극단으로 밀면 과최적화다.
ROC 12~18 / 임계 3~5% / TP 4R / ADX20 이 강건한 스위트스팟.
